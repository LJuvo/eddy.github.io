项目概述

四川诺水河珍稀水生动物国家级自然保护区综合管理平台 UI 设计规范

项目名称

四川诺水河珍稀水生动物国家级自然保护区综合管理平台

平台构成

  • PC 管理端 - 数据管理与分析中心
  • 移动巡护 APP - 现场巡护与数据采集

设计目标

  • 统一 PC 端与移动端的视觉语言
  • 建立专业、可信的保护区平台形象
  • 提升数据可读性与操作效率
  • 适配野外巡护的恶劣使用环境

适用范围

Web 应用 PC 管理端 移动端 Web 原生 APP 数据可视化 GIS 地图

动效规范

清晰、克制的动效系统，提升交互反馈而不干扰用户

过渡时长

150ms 快速 Hover、按钮点击、小状态切换
250ms 常规 面板切换、选项卡、展开/收起
350ms 缓慢 弹窗入场、抽屉滑出、页面转场

PC / 移动端差异对照

同一组件在 PC 端与移动端的关键差异对比

组件PC 端移动端
导航 左侧固定侧边栏，240px 宽，图标+文字，可展开收起二级菜单 底部 Tab 栏，52px 高，4~5 个入口，图标为主+文字辅助，支持中间突出按钮
按钮 默认高度 36px，支持悬停态，可并排显示多个操作按钮 默认高度 44px（保证点击区域），底部悬浮主按钮，操作按钮常以图标形式呈现
表单 多列布局，标签左对齐，输入框 320px 宽，支持 Tab 键切换 单列全宽布局，标签顶对齐，输入框 100% 宽度，唤起系统键盘适配
表格 标准行高 48px，支持列排序、筛选、批量操作、固定列 卡片列表替代表格，或横向滚动表格，行高 64px，支持左滑操作
弹窗 居中弹窗，最大宽度 480px，点击遮罩可关闭，支持拖拽 底部上滑的 ActionSheet 或全屏弹窗，支持手势下滑关闭
搜索 顶部工具栏嵌入，支持回车触发，展示搜索历史下拉 独立搜索页，支持扫码识别、语音输入、实时搜索建议
地图 大屏全量展示，鼠标滚轮缩放，右键菜单，多图层叠加控制面板 手势缩放/旋转，定位按钮常驻，图层切换底部弹出，支持离线底图
拍照 上传本地图片，支持批量拖拽，图片预览侧边栏 调用系统相机，现场拍摄+水印定位，支持连拍与快速标注
分页 页码分页器，可跳转页码，每页条数选择 无限滚动加载，底部加载提示，支持下拉刷新
通知 右上角 Badge + 消息中心弹层，支持标记已读 系统推送 + 应用内红点，消息列表页全屏展示
离线 弱提示，自动重连机制，数据实时同步 强提示（顶部横幅），本地队列存储，手动/自动同步切换
